# DzBusiness Pro — Mobile (تطبيق المدير / Application du gérant)

تطبيق Flutter للهاتف يتيح لمدير المحل متابعة نشاطه التجاري مباشرة.

## الفكرة / المبدأ

البرنامج المكتبي (DzBusiness Pro) يعمل دون إنترنت. عند تشغيل الخيار
**الأدوات ← جوال المدير ← تشغيل** من البرنامج المكتبي:

1. يفتح الكمبيوتر سيرفر **للقراءة فقط** (HTTP) على شبكة المحل المحلية (Wi-Fi).
2. يظهر رمز اقتران من 6 أرقام + رمز QR.
3. يفتح المدير هذا التطبيق على هاتفه، يتصل بنفس شبكة Wi-Fi، يُدخل العنوان والرمز.
4. التطبيق يعرض: مبيعات اليوم/الأسبوع/الشهر، الأرباح، المخزون المنخفض والنافد، ديون العملاء والموردين، الشيكات المستحقة، أكثر المنتجات مبيعاً، ورسم مبيعات آخر 14 يوماً.

كل الأرقام تأتي مباشرة من قاعدة بيانات SQLite الفعلية للمحل — لا بيانات وهمية.

## الأمان / Security

- السيرفر للقراءة فقط: لا يوجد أي مسار كتابة/تعديل/حذف (GET فقط).
- كل طلب يتطلب رمز الاقتران (`Authorization: Bearer`).
- الرمز يتغير في كل تشغيل للسيرفر ولا يُخزَّن.
- لا يمكن الوصول من خارج شبكة المحل (لا يوجد فتح للمنافذ نحو الإنترنت).
- إذا تغيّر الرمز (إعادة تشغيل السيرفر)، يطلب التطبيق إعادة الاقتران تلقائياً.

## البناء / التشغيل

```bash
cd mobile
flutter pub get
flutter run                  # هاتف متصل أو محاكي
flutter build apk --release  # نسخة APK للتوزيع
```

الملف الناتج: `mobile/build/app/outputs/flutter-apk/app-release.apk`

## الحدود / Limites

متابعة (مراقبة) فقط — العمليات المالية والمخزنية تبقى في البرنامج المكتبي.
